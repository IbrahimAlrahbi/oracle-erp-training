
MASTER DETAIL FORM
==================================================

FORM FILE:
IbrahimMasterDetailForm.fmb

FORM MODULE:
IBRAHIMMASTERDETAILFORM


1. CREATE NEW FORM MODULE
=========================

ORACLE FORMS BUILDER
    -> File
        -> New
            -> Form


Form Module:
IBRAHIMMASTERDETAILFORM


2. CREATE WINDOW
================




3. CREATE CANVAS
================

ORACLE FORMS BUILDER
    -> Object Navigator
        -> Canvases
            -> CAN_DEPT_EMP

Canvas Name:
CAN_DEPT_EMP


4. CREATE DATA BLOCK - DEPT
===========================

ORACLE FORMS BUILDER
    -> Object Navigator
        -> Data Blocks
            -> DEPT

Table:
DEPT

Key Column:
DEPT.DEPTNO

Key Type:
Primary Key


5. CREATE DATA BLOCK - EMP
==========================

ORACLE FORMS BUILDER
    -> Object Navigator
        -> Data Blocks
            -> EMP

Table:
EMP

Key Column:
EMP.DEPTNO

Key Type:
Foreign Key


6. CREATE MASTER-DETAIL RELATIONSHIP
====================================

Master Block:
DEPT

Detail Block:
EMP

Relationship:

DEPT.DEPTNO
    -> EMP.DEPTNO


Master:
DEPT

Detail:
EMP


IMPORTANT:
A Master record cannot be deleted while dependent Detail records exist.



8. SAVE THE FORM
================

ORACLE FORMS BUILDER
    -> File
        -> Save As

File Name:
IbrahimMasterDetailForm.fmb


9. COMPILE THE FORM
====================

ORACLE FORMS BUILDER
    -> Program
        -> Compile Module

Source File:
IbrahimMasterDetailForm.fmb

Compiled File:
IbrahimMasterDetailForm.fmx


10. CONNECT TO ORACLE EBS SERVER & MOVE COMPILED FORM
======================================================

Open:
WinSCP

Using the credentials in the file


Move:
IbrahimMasterDetailForm.fmx

To:

/u01/install/VISION/fs1/EBSapps/appl/fnd/12.0.0/forms/US
