1. Add responsibility
2. Open Oracle Workflow Builder
3. Click: File > Quick Start Wizard 
4. Set:
	Internal Name: IBRA_WF
	Display Name: IBRA_WF
Click <Ok>

5. Adding Notification
	- Right click on 'Message' > New Message
	- Set:
		Internal Name: IBRA_MSG
		Display Name: IBRA_MSG
		Add Body: 'HELLO IBRAHIM WELCOME TO OWF'
Click: <Apply> > <Ok>

6. Attache message to notification

	- Right click on Notification > New Notification
	- Set:
		Internal Name: IBRA_NOTIFY
		Display Name: IBRA_NOTIFY
		Message: IBRA_MSG
Click: <Apply> > <Ok>

7. Drag and drop notification 'IBRA_NOTIFY' between 'Start' and 'End'
8. Configure start and end by hold right click on start drag until IBRA_NOTIFY then from IBRA_NOTIFY drag until End
9. Right click in 'IBRA_NOTIFY' > Node > under performer set Value to: 'IBRAHIM'
10. Attache workflow to the database
	Click the on IBRA_WF > File > Save As > click Database (APPS, apps, ebsdb)
