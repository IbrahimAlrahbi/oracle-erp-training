CREATING LOV IN FORMS

IN FORM BUILDER
================
1. OPEN ORACLE FORMS
2. CLICK CANVAS > CREATE 
3. RIGH. CLICK ON CANVAS > PROPERTY PALETTE. 
4. GIVE NAME 'CAN_EMP'
5. CLICK ON DATA BLOCKS > CREATE >USE DATA BLCOK WIZARD > NEXT > TABLE OR VIEW > ENTER 'EMP'
6. MOVE ALL COLUMNS > NEXT > GIVE BLOCK NAME 'EMP' > NEXT > FINISH > NEXT... > SELECT TABULAR > SET FRAME TITLE AS 'EMP DETAILS'
7. CLICK LOV > CREATE > WIZARD > NEXT > WRITE QUERRY 'SELECT DEPTNO FROM EMP' > NEXT > MOVE DEPTNO TO RIGHT > NEXT > SELECT 'RETURN VALUE' > CLICK 'LOOK UP RETURN ITEM' > CHOOSE 'EMP.DEPTNO' > NEXT...
8. RIGHT CLICK LOV IN RECORD GROUP > PROPERTY PALETTE > ADD NAME 'RG_DEPTNO'
9. CLICK LOV IN LOVs > ADD NAME 'LOV_DEPTNO'
10. CHANGE NAME OF MODULE: 'IBRAHIM_EMP_LOV'
11. CLICK MODULE > FILE > SAVE > SAVE IT IN MY FOLDER AS .fmb
12. COMPILE 


REGISTER FORM IN EBS
======================
1. MOVE THE COMPILED FILE TO EBS SERVER USING WINSCP
2. REGISTER THE FORM

	APPLICATION DEVELOPER
	    -> Application
	        -> Form
3. CREATE THE FORM FUNCTION

	APPLICATION DEVELOPER
	    -> Application
   	     	   -> Function
4. ADD THE FUNCTION TO THE MENU


	APPLICATION DEVELOPER
 	   -> Application
    		  -> Menu

5. SWITCH TO MY RESPONSIBILITY 'IBRAHIM_FORMS_RESP'
6. CHOOSE IBRAHIM_EMP_LOV 
7. QUERRY > EXECUTE 
8. OPEN IBRAHIM_FORMS_RESP
	->  IBRAHIM_EMP_LOV

9. ACTION > CLEAR ALL 
10. FILL THE FIELDS 
11. ACTION > SAVE

12. CHECK SQLPLUS 
	SELECT * FROM EMP WHERE DEPTNO = 30;
