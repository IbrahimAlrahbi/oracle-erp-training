Firefox

Oracle EBS Login Page

=================================

operations

<Enter Default Password>

=======================

4. ENTER NEW USER DETAILS
=========================

In the Users form, enter:

User Name:
<Enter New User Name>

Password:
<Enter Temporary Password>

Press:
TAB

Re-enter Password:
<Confirm Temporary Password>


5. ASSIGN RESPONSIBILITIES
==========================

In the Responsibilities section:

Add the required Responsibilities.

Example:

APPLICATION DEVELOPER
SYSTEM ADMINISTRATOR
IBRAHIM_RESP
IBRAHIM_FORMS_RESP

Add only the Responsibilities required for the user.

Save Icon
